## 🧠 How my RAG pipelines work

```mermaid
flowchart LR
    A[📄 Documents<br/>& Odoo records] --> B[✂️ Chunk]
    B --> C[🔢 Embed]
    C --> D[(🗄️ Vector store)]
    Q[❓ User question] --> E[🔢 Embed query]
    E --> F{🔍 Top-k search<br/>+ access filter}
```
